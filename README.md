# pt-ctb-verify

Callback page for the PT-CTB Discord bot's `/verify` command. After a user authorises on osu!, osu! redirects
here; the page just shows the address so they can copy it back into Discord. It sends nothing anywhere.

Served by GitHub Pages at https://123tris.github.io/pt-ctb-verify/. The source of truth is
`verify-page/index.html` in the bot repo; copy changes here.
